# Gemma Skills

AI Edge Gallery skills for on-device agent workflows.

## WordArt Gallery

`wordart-gallery` creates an animated gallery of WordArt treatments for a supplied name using the `@codeweaver/wordart` web component.

After this repository is published with GitHub Pages enabled, load the skill in AI Edge Gallery with this folder URL:

```text
https://anxkhn.github.io/gemma-skills/wordart-gallery
```

You can verify the hosted skill manifest at:

```text
https://anxkhn.github.io/gemma-skills/wordart-gallery/SKILL.md
```

## Image Transform Studio
